# ITOL (*Interactive Tree Of Life*)

## Overview
**ITOL** is an online tool for the display, annotation, and management of phylogenetic and phylogenetic-associated trees. It supports standard formats such as Newick (`.nwk`), Nexus, and PhyloXML.

## Key Features in Pipeline
- **Tree Layouts**: Rectangular, circular, radial, and unrooted representations.
- **Metadata Annotation**: Visual overlay of bootstrap support values, node divergence timelines (Mya), taxonomy color strips, and accession links.
- **Export Formats**: Vector graphics (SVG, PDF) and publication-ready bitmaps for molecular evolution papers.
